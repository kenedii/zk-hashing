Demo · Classical baseline

Password flow

Producing an Argon2id STARK is not feasible in a browser today. This demonstration substitutes a signature for the proof so that the message flow can be exercised with any password against a live server.

Interactive password flow

Construction. The browser computes y=Argon2idθ(w,s) with θ=(32 MiB,3,1), derives a secp256k1 scalar 𝗌𝗄=HKDF(y) mod (q−1)+1, and at login returns a BIP-340 Schnorr signature on ℋ(protocol ∥ account ∥ n). The server stores 𝗉𝗄=𝗌𝗄⋅G. This demonstrates possession of the derived key only. It does not attest to the hash or parameters used, a captured signature permits offline guessing, and the discrete-logarithm assumption on secp256k1 does not hold against a quantum adversary.
