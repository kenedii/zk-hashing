Interactive password flow

Construction. The browser computes $y = \mathrm{Argon2id}_{\theta}(w, s)$ with $\theta = (32\,\text{MiB}, 3, 1)$, derives a secp256k1 scalar $\mathsf{sk} = \mathrm{HKDF}(y) \bmod (q-1) + 1$, and at login returns a BIP-340 Schnorr signature on $\mathcal{H}(\text{protocol} \,\Vert\, \text{account} \,\Vert\, n)$. The server stores $\mathsf{pk} = \mathsf{sk}\cdot G$. This demonstrates possession of the derived key only. It does not attest to the hash or parameters used, a captured signature permits offline guessing, and the discrete-logarithm assumption on secp256k1 does not hold against a quantum adversary.
