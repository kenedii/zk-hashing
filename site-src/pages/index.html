Proving password hashes inside a STARK

Conventional login sends the password to the server, which hashes and compares it. This project studies the alternative: the client executes the complete password hash inside a virtual machine and submits a succinct proof that the result matches the value registered with the server. The password is a private input to the proof and is never transmitted.
